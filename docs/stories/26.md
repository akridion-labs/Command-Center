# Story 26 - knowledge gaps panel

## Goal
To display the open questions from the `/vyom/gaps` endpoint in a dedicated panel on the Vyom Command Center dashboard, showing the question, how many times it's been asked, and when it was last asked, with the newest gaps listed first.

## User journey
1. User navigates to the Vyom Command Center dashboard
2. User sees the new knowledge gaps panel alongside other panels
3. User views the list of open questions from `/vyom/gaps`
4. User sees the count of times each question was asked and when it was last asked
5. User can copy commands from the panel if needed

## Acceptance criteria
AC1. The panel displays a list of knowledge gaps fetched from the `/vyom/gaps` endpoint
AC2. Each gap shows the question text, number of times asked, and when it was last asked
AC3. Gaps are displayed newest first (most recent first)
AC4. The panel shows "No gaps found" when there are zero gaps
AC5. The panel displays loading state while fetching data
AC6. The panel shows appropriate error messages for failed requests
AC7. The panel displays NOT BUILT state with the reason when the endpoint is not built
AC8. The panel shows "not permitted for your role" when user lacks access
AC9. Commands from the gaps are shown in monospace format with a copy button

## States
- Empty: Shows "No gaps found" message
- Loading: Shows loading spinner or skeleton
- Built with rows: Displays list of gaps with question, times asked, and last asked date
- NOT BUILT: Shows "not built" message with the reason from the endpoint
- Not permitted: Shows "not permitted for your role" message
- Error: Shows error message with details

## Out of scope
- Adding new gaps or managing gaps through this panel
- Filtering or sorting capabilities beyond showing newest first
- Detailed gap analysis or history beyond times asked and last asked
