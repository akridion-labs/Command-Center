# Story 24 - Build Loop Panel

## Goal
To provide a comprehensive overview of the build loop status in the Vyom Command Center dashboard, allowing team members to quickly assess the progress of various build slices and take appropriate actions based on their current state.

## User journey
1. User navigates to the Vyom Command Center dashboard
2. User locates the Build Loop panel on the deck
3. User views the list of build slices grouped by their state (done, waiting for review, parked, needs review, yours, to do)
4. User examines each slice's status line and next command if available
5. User identifies who finished each slice through the `finished_by` field
6. User verifies tests pass in `src/panels/Build.test.tsx`

## Acceptance criteria
AC1 The panel displays build slices grouped by their state (done, waiting for review, parked, needs review, yours, to do)
AC2 Each slice shows its status line with relevant information
AC3 When a slice has a next command, it is displayed in monospace text with a Copy button
AC4 The panel shows who finished each slice through the `finished_by` field
AC5 The panel displays loading state while fetching data
AC6 The panel shows empty state when there are no build slices
AC7 The panel shows error state when the API call fails
AC8 The panel shows NOT BUILT state with appropriate reason when the endpoint is not built
AC9 The panel shows permission denied state when user lacks access to the endpoint

## States
- Loading: Shows loading spinner while fetching data from `/vyom/build`
- Empty: Displays "No build slices found" message when there are no slices
- Error: Shows error message with details when API call fails
- NOT BUILT: Displays "Not built" with the reason from `why` field
- Permission Denied: Shows "Not permitted for your role" when user lacks access
- Normal: Displays grouped slices with status lines, next commands (when available), and finished_by information

## Out of scope
- Detailed slice information beyond what's provided in the API
- Interactive actions on slices within this panel
- Integration with external build systems beyond the `/vyom/build` endpoint
