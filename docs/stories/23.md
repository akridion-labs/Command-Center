# Story 23 - Command Center Design Refresh

## Goal
To apply the design-scout findings from the "ojas web-review" to refresh the Vyom Command Center's user interface, ensuring consistent spacing, visual hierarchy, and appropriate density while maintaining the reference design's color scheme and typography.

## User journey
1. Developer accesses the Vyom Command Center console at `:8765/console/`
2. User views the refreshed dashboard with updated visual design elements
3. User interacts with components to verify that spacing, hierarchy, and density match the design specifications
4. User confirms that all design bindings are properly connected to actual data sources
5. User validates that the application renders correctly under CSP restrictions

## Acceptance criteria
AC1. The dashboard layout uses consistent spacing as defined in the design-scout findings
AC2. Visual hierarchy is established through appropriate font weights, sizes, and color contrasts
AC3. Content density matches the reference design's specifications
AC4. All visual elements use the reference design's color palette
AC5. Typography follows the reference design's font choices (Rajdhani, JetBrains Mono)
AC6. Components maintain proper alignment and responsive behavior
AC7. The dashboard renders correctly under CSP restrictions with no external script/font references
AC8. All data bindings from the design map to actual API endpoints or NOT BUILT states

## States
Empty: Dashboard loads with placeholder elements showing loading state
Loading: Spinner or skeleton loaders displayed while components fetch data
Error: Error message displayed with clear indication of what went wrong
NOT BUILT: Panel shows "not built" with explanation of why the feature is not available
Not permitted: Access denied message with appropriate error handling

## Out of scope
- Implementation of new features beyond the existing endpoints
- Changes to backend API behavior or data structure
- Modifications to security headers or CSP policies
- Updates to authentication flow or user roles
- Integration with external services or third-party libraries beyond what's specified
